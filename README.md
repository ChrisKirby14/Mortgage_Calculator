# UK Mortgage & Property Purchase Calculator

An interactive, user-friendly web application built with Python and Streamlit designed to help home movers calculate available capital from a property sale and forecast remaining funds after purchasing a new home—featuring dynamic UK Stamp Duty marginal tax bracket calculations.

---

## Features

* **Property Sale Breakdown:** Calculates net available funds by accounting for outstanding mortgage amounts, Early Repayment Charges (ERC), estate agent percentage fees, solicitor conveyancing fees, and moving costs, combined with personal savings.
* **UK Stamp Duty Tier Engine:** Automatically computes tiered marginal Stamp Duty Land Tax (SDLT) across standard UK residential property brackets (0%, 2%, 5%, 10%, and 12%).
* **Property Purchase Forecasting:** Subtracts the new house price, surveyor fees, and calculated Stamp Duty to determine final remaining liquidity.
* **Responsive UI:** Clean, formatted financial outputs built with Streamlit for seamless user interaction.
